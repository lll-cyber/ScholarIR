# Thread：轻量槽位实现说明

> 日期：2026-08-20（更新 2026-08-23）
> 代码：`src/scholar_ir/understanding/`

## 设计分工（按讨论）

| 部分                    | 作用                                       | 影响                                           |
| ----------------------- | ------------------------------------------ | ---------------------------------------------- |
| **intent**        | 路由 + 扩写策略                            | **召回**                                 |
| **slots**（轻量） | year / venue / authors / method / negation + **`terms[]`** | **过滤 + Judge + 术语扩写** |
| **topic**         | 改写种子 + Judge 主题条件                  | 两者都用                                       |

> 扩写素材（abbrev/synonyms/instances）挂在 `slots.terms[]`，**不再**单独 `recall_hints`。  
> 完整规格：`2026-08-26-Understanding完整设计.md`

## 冻结的轻量字段

- intent ∈ `{survey, method, dataset, specific, broad, related}`
- slots：`topic, method, year_from, year_to, venue, authors, negation`
- `negation` **不进** Retrieval filters，只进 `relevance_criteria`

## 流水线（2026-08-23 已实现；2026-08-26 v2.1 规划见下）

> **下一版规格**：`thread/2026-08-26-angle与SlotUsage-v2.1.md`（angle=transform、SlotUsage、P0 不做 subdomain）

```text
Round 1  llm_extract / heuristic
         → intent, slots（含 terms[]）

Usage Decision  usage_decision.py（代码表，不进 LLM）
         → api_filters（默认 recall_mode：method 不进 filter）
         → use_llm_expand（specific 跳过）

Round 2  llm_expand.py（survey/broad/method/related/dataset）
         → 4–5 条 {text, angle} 互斥子查询

Assemble  assemble.py
         → SubQuery + filters + angle
         → specific：metadata 通道，不扩写
         → fallback：rewrite_by_intent 模板
```

| 文件 | 职责 |
|------|------|
| `llm_extract.py` | Round 1：intent + slots（目标态含 `terms[]`） |
| `usage_decision.py` | slot → api_filter / judge-only / 是否二轮扩写 |
| `llm_expand.py`     | Round 2：互斥 recall 子查询                    |
| `assemble.py`       | 组装 SubQuery（含 lexical 变体）               |
| `base.py`           | `understand()` 编排                          |

## 选项

- `max_subqueries`：默认 **5**
- `recall_mode`：默认 **true**（method 仅 Judge，不进 api_filter）
- `use_llm`：false 时全程启发式 + 模板
